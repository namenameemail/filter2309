# OPT-06 — Облегчение DSP патча (условный)

**Статус:** todo  
**Зависит от:** opt-02 (делать, если realtime factor < 3 или нужен запас для слабых машин)  
**Блокирует:** opt-08

## Цель

Снизить стоимость DSP без изменения звучания активных выделений.

## Кандидаты (по профилю из opt-02)

1. `switch~` в `noise.pd`: неактивные выделения не считаются.
2. Убрать/выключить отладочные `tabwrite~` (`r metr`).
3. Проверить число `osc~`/`expr~` на голос; `expr~` → нативные объекты.
4. SIMD-сборка libpd, если не сделано в opt-02.

## Done when

- realtime factor ≥ 3 в худшем сценарии;
- A/B прослушивание: звучание активных выделений не изменилось.
