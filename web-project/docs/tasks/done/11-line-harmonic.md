# 11 — Линия 2: гармоники внутри выделения

**Статус:** done  
**Зависит от:** [10-line-types.md](../10-line-types.md)  
**Блокирует:** —

## Цель

Это не новый тип линии. У типа **2** два параметра: количество гармоник и расстояние. Сам отрезок типа 2 остаётся как есть: от точки нажатия до курсора, превью пока кнопка зажата, в `fbo` один раз при отпускании.

Расстояние задаётся в герцах. В пиксели его переводит выделение под курсором. Выделение растягивает весь спектр на свою высоту. Формула та же, что в `fillFilterCache`: бин `i` (0…127, дальше клип) ложится в строку

```text
y = sy + (1 - clamp(i * 2 / 255, 0, 1)) * (h - 1)
```

`i = 0` — низ выделения. `block~ 512`, `rfft~`: частота бина `i * sr / 512`. На вебе `sr = 44100`, ширина бина около 86 Гц. Внутри одного выделения равные герцы — равные пиксели. У выделения другой высоты тот же шаг в герцах даёт другой шаг в пикселях.

## Параметры

В списке типа 2, рядом с уже существующими: `harmonics`, `stepHz`.

- `harmonics` — количество гармоник. Сколько копий сверх самого отрезка. 0 — только отрезок.
- `stepHz` — расстояние между соседними копиями в герцах. В подписи параметра: «расстояние». Минимум не ниже ширины бина: меньший шаг попадает в ту же строку.

## Отрисовка

Курсор внутри выделения, кнопка зажата: отрезок типа 2 и его копии, сдвинутые вверх на 1…`harmonics` шагов. Сдвиг в пикселях считается из `stepHz` и высоты этого выделения. Копия, которая уходит выше верха выделения, не рисуется. Вне выделения — один отрезок, без копий. Пересекающиеся выделения: то, которое уже выбирает хит-тест курсора.

Пока кнопка зажата, в `fbo` ничего не штампуется. На отпускании внутри выделения — отрезок и копии. На отпускании вне выделения — только отрезок.

Курсор внутри выделения, кнопка не зажата: на местах гармоник маленькие полупрозрачные серые крестики. Якорь — точка курсора, крестики на 1…`harmonics` шагах вверх. Это только подсказка, в `fbo` не пишется. Вне выделения крестиков нет. При `harmonics` = 0 крестиков нет.

Отрицательная высота выделения считается той же формулой, что и чтение столбца в фильтр.

## Шаги

1. Добавить `harmonics` и `stepHz` в параметры типа 2. Тип 1 их не показывает.
2. Перевод `y ↔ Гц` из формулы `fillFilterCache` и `sr` того же `rfft~`.
3. Копии отрезка рисовать тем же путём, что и сам отрезок типа 2 (превью в `fbo2`, штамп на отпускании).
4. Крестики рисовать поверх кадра, не в `fbo`.

## Done when

- у типа 2 в цикле есть количество гармоник и расстояние; у типа 1 их нет
- рисование вне выделения — одна линия
- рисование внутри выделения — линия и копии через `stepHz`; в более низком выделении тот же шаг короче в пикселях
- при движении мыши внутри выделения видны серые полупрозрачные крестики на шаге гармоник, в холст они не попадают
- после отпускания в `fbo` один гребень, без следа промежуточных положений
