# OPT-05 — Синхронизация звука и картинки

**Статус:** todo  
**Зависит от:** opt-03, opt-04  
**Блокирует:** opt-08

## Цель

Курсор на экране совпадает с тем, что слышно.

## Шаги

1. Минимизировать буферы: кольцо 512–1024 фреймов, `latencyHint: 'interactive'`.
2. Pd-поток помечает значения курсоров номером фрейма, в котором они посчитаны.
3. Главный поток рисует курсор для `playedFrames + outputLatency` (интерполяция между метками), а не последнее посчитанное значение.
4. Учесть задержку FFT (`block~ 512 4`) — та же, что в нативе; решить, компенсировать ли.
5. Проверка записью экрана со звуком.

## Done when

- рассинхрон ≤ 1 кадра визуально;
- выходная задержка ≤ 50 мс (или зафиксированное обоснованное значение).
