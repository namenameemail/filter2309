# 10 — Линия: несколько типов, у каждого свои параметры

**Статус:** todo

## Цель

У кисти `line` есть тип линии. Типы переключаются отдельным параметром, у каждого свой набор параметров и своя отрисовка. Новый тип добавляется записью в этот список, без отдельной ветки в общем цикле параметров.

- **1** — текущая линия: на драге отрезок от предыдущей точки к курсору, штрих остаётся в `fbo`. Параметры: `lineSize`, `color`, `opacity`.
- **2** — один прямой отрезок от точки нажатия (`buttonsPressed[0].sx/sy`) до курсора. Промежуточные положения на холсте не остаются: пока кнопка зажата, виден только текущий отрезок, в `fbo` он попадает при отпускании. Параметры: `lineSize`, `color`, `opacity`, `gradient`.

`gradient` только у типа 2, radio `on` / `off`.

- `off` — отрезок сплошной, альфа = `opacity`.
- `on` — вдоль отрезка альфа от `opacity` в точке нажатия до 0 в точке курсора.

## Шаги

1. Параметр `lineType` (`"1"`, `"2"`). В `getBrushParamsByCurrentType` и `getVisualBrushParamsByCurrentType` для `line` отдавать параметры активного типа.
2. Тип 1 оставить как есть (`ofDrawLine` от `prevPoint` к курсору).
3. Тип 2 рисовать одним отрезком. Градиент — меш с цветом вершин: `ofDrawLine` альфу вдоль линии не делает.
4. Пока кнопка зажата, отрезок типа 2 не штамповать в `fbo` на каждом драге.

## Done when

- у линии переключается тип, в цикле параметров только параметры этого типа
- тип 1 рисует как сейчас
- тип 2 — один отрезок от нажатия до курсора, без веера
- `gradient` on: от `opacity` к нулю; off: сплошная заливка
