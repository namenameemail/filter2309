# 09 — Save: скачать картинку и кадр с интерфейсом

**Статус:** todo  
**Зависит от:** 06  
**Блокирует:** —

## Цель

По клавише пользователь скачивает PNG из браузера. Записи в MEMFS нет.

- `;` — только картинка (`fbo2`, без оверлеев).
- `'` — то, что на экране: картинка вместе с интерфейсом (выделения, легенда и прочее, что рисуется после `fbo2:draw`).

`saveFBO2` на emscripten уже выходит сразу и на диск не пишет. Автосейв не возвращать.

## Шаги

1. В `M.keyPressed` повесить `;` и `'`.
2. `;`: `fbo2:readToPixels` → PNG → download (blob / `<a download>`).
3. `'`: пиксели текущего кадра окна (картинка + интерфейс) → тот же download.
4. Имя файла с меткой времени. `saves/` в data-пакет не класть.

## Done when

- `;` скачивает PNG без интерфейса
- `'` скачивает PNG с интерфейсом
- в MEMFS ничего не пишется
